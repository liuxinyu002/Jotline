08

变量 Tokens

全部以 CSS Custom Property 交付，变量名与暖调版完全一致 —— 直接替换 :root 即可从暖调整套切到冷调。点击任意行复制声明。

❄️ 全冷极简变体：若想彻底去掉暖色，把 --c-sun 改为 #B9C0E8（与蓝铃紫复用）即可，其余变量不动。功能色 #34C759 / #E5484D 恒定，请勿随主题漂移。
